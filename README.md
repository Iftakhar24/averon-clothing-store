# AVERON – Premium Fashion Store
A modern, responsive clothing store homepage built with React.js. AVERON brings together elegance, comfort, and contemporary fashion in a clean and premium shopping experience.


## Live Demo
[Visit AVERON Live Website](https://averon-clothing-store.netlify.app/)


## GitHub Repository
[View Source Code](https://github.com/Iftakhar24/averon-clothing-store)


## Project Overview
AVERON is a premium fashion destination inspired by timeless elegance and contemporary style. Built with React.js, it features a refined luxury-inspired interface, curated fashion collections, interactive product discovery, and seamless responsive experiences.



## Features
- Modern and premium fashion-themed UI
- Responsive design for desktop, tablet, and mobile
- Hero section with collection banner and CTA
- Navigation bar with search functionality
- 30 fashion products across Men, Women, and Premium categories
- Product category filtering
- Product search functionality
- Reusable React components
- Newsletter subscription interface
- Smooth scrolling and subtle animations
- Back-to-top button
- Footer with navigation and social links

## Installation and Setup
Follow these steps to run the project locally.

### 1. Clone the repository
git clone https://github.com/Iftakhar24/averon-clothing-store.git

### 2. Navigate to the project directory
cd averon-clothing-store

### 3. Install dependencies
npm install


### 4. Start the development server
npm run dev


### 5. Create a production build
npm run build
